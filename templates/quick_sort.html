💻 Partition Code Execution Python 3
pivot = arr[low]
left = low + 1; right = high
while True:
while left <= right and arr[left] < pivot:
left += 1
while left <= right and arr[right] > pivot:
right -= 1
if left > right: break
arr[left], arr[right] = arr[right], arr[left]
arr[low], arr[right] = arr[right], arr[low]

How Partitioning Works:

The pivot element is placed in its true final sorted position. All items strictly less than the pivot are placed to its left, and all items greater are placed to its right.
