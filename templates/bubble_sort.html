def bubble_sort(arr):
n = len(arr)
for i in range(n):
for j in range(0, n - i - 1):
# Compare adjacent
if arr[j] > arr[j+1]:
# Swap values
arr[j], arr[j+1] = arr[j+1], arr[j]
return arr

Why is it called "Bubble" Sort?

Like bubbles rising in water, in every pass through the array, the largest remaining unsorted element bubbles up to its final position at the end of the array.
