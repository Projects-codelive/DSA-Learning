def merge_sort(arr):
if len(arr) <= 1: return arr # Base leaf
mid = len(arr) // 2 # Midpoint
# Recursive division
left = merge_sort(arr[:mid])
right = merge_sort(arr[mid:])
# Compare & Merge halves
return merge(left, right)

Why Merge Sort is Guaranteed O(n log n):

The recursion tree depth is strictly log₂(n) levels. At each level, the total merging work across all subarrays is O(n). Thus: T(n) = O(n log n) in best, average, and worst cases!
