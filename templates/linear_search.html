def linear_search(arr, target):
for i in range(len(arr)):
if arr[i] == target:
return i # Match!
return -1 # Not found

Key Linear Search Properties:

• Unsorted friendly: Does not require elements to be in sorted order.
• Best case O(1): Target is found immediately at index 0.
• Worst case O(n): Target is at the very end or absent.
