low, high = 0, len(arr) - 1
while low <= high:
mid = (low + high) // 2
if arr[mid] == target:
return mid # Found!
elif arr[mid] < target:
low = mid + 1 # Eliminate left
else:
high = mid - 1 # Eliminate right
return -1 # Not found

Why O(log n) is Ultra-Fast:

At each comparison, half of the entire search space is permanently discarded. In an array of 1,000,000 elements, Binary Search needs at most 20 comparisons to find any target!
